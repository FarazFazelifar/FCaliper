# FCaliper — Original Python Version

This repository contains the original Python implementation of FCaliper, software for viewing ECG images and making manual measurements.

I developed the software for ECG measurements used in published research. I later rebuilt the application with a new desktop interface using Tauri, Rust, and TypeScript.

For the current implementation and its build instructions, see [FCaliper-modern](https://github.com/FarazFazelifar/FCaliper-modern).

## Repository contents

The repository includes the original application source files and packaging scripts. The installer and finished executable are **not** included.

This is a historical version of the project. I recommend using the modern repository when evaluating or building FCaliper today.

## Research

The measurement software has been used in two peer-reviewed studies:

- [QRS Complex Duration and Area as Indicators of Response to Cardiac Resynchronization Therapy (CRT)](https://doi.org/10.1111/pace.70053) — *Pacing and Clinical Electrophysiology*, 2025.
- [Electrocardiographic Manifestations of Pulmonary Stenosis versus Pulmonary Hypertension](https://doi.org/10.1016/j.jelectrocard.2023.08.010) — *Journal of Electrocardiology*, 2023.

My contribution was developing and maintaining the measurement software and helping the authors use it.
